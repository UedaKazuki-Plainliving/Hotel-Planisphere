## 6. トレーサビリティの課題と改善推奨

| 課題 | 影響 | 推奨アクション |
|---|---|---|
| 手動テストとATDDの対応関係が未文書化 | 重複テストの管理ができない | test_cases.mdにATDDシナリオIDの参照列を追加 |
| 探索テストBUG25件のうち手動テスト追確認ゼロ | バグの再現・回帰テストができない | BUG対応テストケースを順次追加（優先：BUG-001〜004/020）|
| @missing-feature 7件の除外理由が未記載 | 実装後のテスト漏れリスク | test_design.mdに「テスト対象外機能」セクションを追加 |
| 性能基準の矛盾（3秒 vs 5秒）| テスト結果の判定が文書によって異なる | プロジェクトで基準を統一（推奨：3秒）し両文書を修正 |
| セキュリティテストのカバレッジが低い（30%）| 重大な脆弱性が未検出のまま残るリスク | セキュリティ専門レビューを実施し ST-NF を拡充 |
