## このドキュメントの使い方

1. テストを始める前に **テスト設計書（test_design.md）** を必ず読んでください
2. テストケースは **上から順番に** 実施してください
3. 各テストの「手順」を1ステップずつ読みながら操作してください
4. 「期待結果」と実際の画面を見比べて「判定」欄に記入してください

### 記録欄の書き方

| 記号 | 意味 |
|---|---|
| ○ | 期待結果の通りになった（合格）|
| × | 期待結果と異なった（不合格）|
| － | 実施しなかった（理由を記入）|

### UT-001　メールアドレス：正しい形式で入力できる

| 項目 | 内容 |
|---|---|
| テストレベル | 単体テスト |
| テスト技法 | 同値分割 |
| 対象ページ | 会員登録ページ |
| ユーザークローン観点 | 入力できる値の確認（正常系の基準として）|

**前提条件**
- パソコンを起動し、インターネットに接続されている
- Google Chrome ブラウザが開いている
- ログインしていない状態である

**テスト手順**

1. Chrome のアドレスバー（画面上部の長い入力欄）をクリックする
2. 以下のアドレスを入力して **Enter** キーを押す  
   `https://hotel-example-site.takeyaqa.dev/ja/signup.html`
3. 「会員登録」というタイトルのページが表示されることを確認する
4. 「メールアドレス」の入力欄をクリックして `user001@example.com` と入力する
5. 「パスワード」の入力欄に `password01` と入力する（文字は●で隠れる）
6. 「確認用パスワード」の入力欄に `password01` と入力する
7. 「氏名」の入力欄に `テスト 太郎` と入力する
8. 「登録」ボタン（青いボタン）をクリックする

**期待結果**
- エラーメッセージが表示されない
- 「マイページ」の画面に切り替わる

**判定　　　　○　 ／　 ×**

**メモ欄**  
_（実際に起きたこと・気になったことを記入してください）_
